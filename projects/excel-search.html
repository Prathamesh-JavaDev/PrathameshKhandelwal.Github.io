Excel Searcher App

A Java desktop application built with JavaFX, Apache POI, and Maven to search Excel workbooks across sheets and cells for exact and similar data tuples.

Problem

Operational teams often need to locate matching records inside large Excel workbooks. Manual search is slow when data spans multiple sheets, especially when the goal is to compare exact and similar data tuples.

Solution

The application reads workbooks with Apache POI, scans sheets and cells, and supports advanced search behavior for exact and similar matches. It helps users find relevant tuples quickly while keeping the interface lightweight through JavaFX.

Architecture

  • JavaFX UI: Provides desktop interaction for file selection and searching
  • Apache POI Layer: Reads workbook sheets, rows, and cells
  • Search Engine: Detects exact and similar tuples across workbook data
  • Loader System: Dynamically detects and manages system version files

Execution Flow

  1. User selects an Excel workbook and enters search input.
  2. The UI validates input and starts the search.
  3. ExcelReader loads the workbook through Apache POI.
  4. The system scans all sheets and cells for exact and similar data tuples.
  5. Matching results are collected and returned to the UI.
  6. The loader system manages version files for scalability and maintainability.

Technical Highlights

  • Supports .xls and .xlsx files
  • Built with JavaFX, Apache POI, and Maven
  • Scans all sheets and cells for broader match coverage
  • Supports exact and similar tuple search
  • Includes a loader system for dynamic version-file management

Improvements

Future versions can introduce streaming reads for very large files, indexing for faster repeated searches, exportable result sets, and additional filters for domain-specific workbook data.
