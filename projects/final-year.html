Crypto-Tool

Overview

Crypto-Tool is a Java-based desktop application created to demonstrate multiple cryptographic techniques within one modular tool. The project focused on making encryption workflows understandable, extensible, and easier to compare.

Leadership & Contribution

  • Led a team of five through project planning, task division, and implementation.
  • Built a modular architecture so different encryption algorithms could be plugged into the tool.
  • Implemented symmetric and asymmetric encryption workflows in Java.
  • Coordinated feature integration and testing across the team.

Custom Algorithms

The project included two custom algorithm experiments: a Bit Manipulation Fixed Key Algorithm and an Arithmetic No Key Algorithm. These were designed to explore how transformations can be structured and compared inside a consistent application flow.

Technical Highlights

  • Java desktop application with modular cryptographic components
  • Pluggable structure for adding or comparing algorithms
  • Symmetric and asymmetric encryption support
  • Custom algorithm design and implementation
  • Team-based delivery with leadership responsibility

Outcome

The project strengthened practical Java development, team leadership, modular design, and applied cryptography fundamentals while producing a complete academic desktop tool.
